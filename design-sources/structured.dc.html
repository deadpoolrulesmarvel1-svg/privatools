What local-first means

A local-first tool does its work in the browser on your device. The file is read where it already sits, the result is written back to the same place, and no copy travels to a server. That is the default here, and every tool says which mode it uses before you start.

lightbulb

If a tool cannot finish on your device, we say so and name the location: Mumbai, India. The file is processed in an isolated request and deleted immediately after the response.
